# SCSS Toolkit

Небольшой набор SCSS-функций и миксинов для адаптивной вёрстки: перевод значений в `rem`, плавное изменение размеров, медиазапросы, позиционирование и управление видимостью элементов.

Сейчас проект содержит только SCSS-хелперы. Демостраницы, `package.json`, сборки и автоматических тестов пока нет. Ниже описаны структура, подключение и существующий API.

## Структура

```text
helpers/
├── _index.scss      # Общая точка входа через @forward
├── _functions.scss  # rem() и fluid()
├── _mixins.scss     # Типографика, размеры, позиционирование и видимость
└── _media.scss      # Брейкпоинты и hover/active-состояния
```

## Подключение

Для компиляции нужен Dart Sass. Хелперы можно скопировать в свой проект и подключить через `@use`. Путь зависит от расположения вашего SCSS-файла.

Например, создайте `demo.scss` в корне этого репозитория:

```scss
@use "./helpers" as kit;

.card {
  position: relative;
  padding: kit.rem(24);
  border-radius: kit.rem(16);

  &__title {
    @include kit.fluid-text(48, 24);
  }

  &__badge {
    @include kit.abs-center;
    @include kit.square(kit.rem(40));
  }

  @include kit.mobile {
    padding: kit.rem(16);
  }
}

.button {
  @include kit.hover {
    background-color: royalblue;
    color: white;
  }
}
```

При установленном Node.js и npm разовую компиляцию можно выполнить из корня проекта:

```bash
npx --yes --package=sass sass demo.scss /tmp/scss-toolkit-demo.css
```

Команда загрузит Sass, если он ещё не доступен в кэше npm. Файл `demo.scss` нужно создать самостоятельно; в текущем репозитории его нет. Результат компиляции появится в `/tmp/scss-toolkit-demo.css`. Для визуальной проверки понадобится HTML-страница с подключённым CSS.

## Функции

### `rem($pixel)`

Делит число на `16` и возвращает значение в `rem`:

```scss
padding: kit.rem(24); // 1.5rem
```

Принимает только число без единицы измерения: `rem(24)`. Вызов `rem(24px)` или передача строки завершит компиляцию с ошибкой. Расчёт основан на 16 px; фактический размер в браузере зависит от размера шрифта корневого элемента.

### `fluid($max: 100, $min: 10)`

Возвращает `clamp()` для плавного изменения размера между минимальным и максимальным значениями:

```scss
font-size: kit.fluid(48, 24);
gap: kit.fluid(32, 16);
```

Аргументы передаются **сначала максимальный, затем минимальный**, числами без единиц измерения. Расчёт использует диапазон ширины окна от 390 до 1920 px при корневом размере шрифта 16 px. Эти границы пока заданы внутри функции; при другом корневом размере шрифта точки достижения пределов смещаются.

В текущей реализации нет проверки аргументов `fluid()`: используйте `$max >= $min` и подходящие для выбранного CSS-свойства значения.

## Миксины

| Миксин | Назначение |
| --- | --- |
| `fluid-text($max: 48, $min: 16)` | Задаёт `font-size` через `fluid()` |
| `hide` | Устанавливает `opacity: 0` и `visibility: hidden` |
| `show` | Устанавливает `opacity: 1` и `visibility: visible` |
| `abs-center` | Абсолютное позиционирование по центру обеих осей |
| `abs-x` | Абсолютное позиционирование по центру горизонтальной оси |
| `abs-y` | Абсолютное позиционирование по центру вертикальной оси |
| `square($size)` | Задаёт одинаковые `width` и `height` |
| `visually-hidden` | Визуально скрывает содержимое, сохраняя его для вспомогательных технологий |

Для `abs-*` обычно нужен родитель с `position: relative`. Эти миксины задают свойство `translate`, поэтому его собственное значение у элемента будет перезаписано.

`square()` принимает готовое CSS-значение, например `2rem`, `40px` или `kit.rem(40)`. `hide` сохраняет место элемента в потоке; `show` сам по себе не отменяет `display: none`. `visually-hidden` подходит, например, для текстовой подписи, но сам по себе не добавляет состояния показа при фокусе.

## Адаптивность и состояния

Каждый медиамиксин принимает блок стилей через `@content`:

```scss
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);

  @include kit.tablet {
    grid-template-columns: repeat(2, 1fr);
  }

  @include kit.mobile {
    grid-template-columns: 1fr;
  }
}
```

| До границы включительно (`<=`) | Выше границы (`>`) | Значение для расчёта |
| --- | --- | --- |
| `laptop` | `laptop-above` | 1440.98 |
| `tablet` | `tablet-above` | 1023.98 |
| `mobile` | `mobile-above` | 767.98 |
| `mobile-s` | `mobile-s-above` | 480.98 |

В медиазапросах значения переводятся в `rem`. Для медиазапросов относительные единицы зависят от исходного размера шрифта браузера; при 16 px границы соответствуют указанным числам в пикселях. Для изменения брейкпоинтов сейчас нужно редактировать переменные в `helpers/_media.scss`.

`hover($hasActiveEffectOnMobile: true)` применяет вложенные стили:

- к `:hover`, если выполняется `(any-hover: hover)`;
- к `:active`, если выполняется `(any-hover: none)` и аргумент равен `true`.

Проверка основана на возможностях устройств ввода, а не на ширине экрана. Чтобы отключить эффект нажатия, используйте `@include kit.hover(false) { ... }`. Состояние клавиатурного фокуса `:focus-visible` нужно описывать отдельно.
